Security hook cold-start cut (task #330 / T8b, swarm run 20261113-bef5ea, branch feature/security-adjudication, 2026-11-13). I CPU-profiled the hook process (node --cpu-prof, 50 us, 15 runs per variant). Security-only mode added about 12 to 15 ms, and almost none of it was module size. (1) loadConfig ran the full zod adjudicator schema whenever `adjudicator.security` was present: +3.5 ms on every hook, Bash included. (2) The first run of each of about 40 cue RegExps compiles it in V8 (0.1 to 0.3 ms each), and the second text (an Agent call's description + prompt) triggers a native tier-up compile: 3 to 6 ms. (3) record(): redact.ts head() and the store's redactSecrets compile their rules, about 1.8 ms (left alone: privacy code). (4) Preparsing the security chunk costs about 1.4 ms. The advice/view builders cost about 0.15 ms, so splitting them out was not worth doing.
Fixes: config.ts parseConfig fast path. An adjudicator section that holds only `enabled: false` plus `security: {enabled: true|false}` now takes adjudicatorDefaults() with that switch and skips zod (securitySwitchOnly; a test pins it equal to the schema's answer). New src/adjudicator/security/prefilter.ts: needlesOf(source, flags) reads each pattern's own source and derives the literals that every match must contain. It is sound by construction: a flag other than g/m/s, a backreference, a named group, \p/\u/\x or a literal brace gives null, and null means the pattern always runs. GatedRegExp (a RegExp subclass) gates test() and matchAll(), so a pattern does not run or compile on text without its needles. signals.ts re()/g()/URL_RE use it. tests/unit/adjudicator-security-prefilter.test.ts checks that every match of every signal pattern on a corpus (eval set + every quoted string in the security tests) holds a needle, and that every signal pattern has a gate.
Bench (scripts/bench-hotpath.mjs --only hooks --hook-runs 25 --base <origin/main build>, run alone), security p50 over its variant: prompt 12.05 -> 8.52 / 7.90 ms, Agent 14.93 -> 8.30 / 7.49 ms, with the adjudicator on 7.72 -> 5.1/6.3 (prompt) and 8.79 -> 5.5/5.4 (Agent). The budget is unchanged. Further options not taken: node module.enableCompileCache() for the hook (compileSourceTextModule is about 14 ms of every hook), and a literal prefilter for the redact.ts rules (most are /gi, which the parser does not model).
