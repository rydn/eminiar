Usage insights (branch feature/usage-insights, v0.10.0, 2026-10-27). `src/usage/` turns Claude Code transcripts into per-model-call depth without a proxy (see decision/usage-insights-no-proxy):
- `transcript.ts` parses JSONL entries; one API response is written as several `assistant` entries sharing requestId + message.id (up to 60 in long tool turns), the first often with placeholder usage (output_tokens 8) and a later one with the final counts, so rows are keyed on (request_id, message_id) and `apiCallsUpsert` takes MAX of every count and reprices when output grew. Image/document result parts count a fixed 6,400 chars (NON_TEXT_PART_CHARS) instead of their base64 length. Tool results that are hook or permission denials (regex DENIAL_RE: "PreToolUse:", "hook error", "denied") are stored with is_error 0 so eminiar's own routing refusals never look like error loops. `<synthetic>` model rows are stored unpriced and skipped by `isRealCall`. compact_boundary → context_events (trigger, preTokens, postTokens); local_command "clear" → kind clear. Subagent transcripts live at `<slug>/<sessionId>/subagents/agent-*.jsonl` with isSidechain true and the parent sessionId.
- `ingest.ts` tails by byte offset (transcript_files: offset, size, mtime, head_hash of the first 512 bytes; restart from 0 on shrink, head change, or mtime change with a non-newline byte at offset-1); session ids are validated (/^[A-Za-z0-9_-]{1,80}$/) and every path is resolved inside `claudeDir()` (env EMINIAR_CLAUDE_DIR, default ~/.claude); only *.jsonl regular files are read. Hooks Stop/SubagentStop/SessionEnd (and SessionStart on resume/compact) ingest the session tail (~10 ms on a 2.6 MB file, no-op when unchanged); em_usage, the API and the CLI run ingestProject behind a 10 s guard per root. Snapshots older than 30 days or beyond 500 per session are pruned during ingest.
- `pricing.ts` bundles list prices (USD/MTok, source platform.claude.com pricing page, PRICING_VERSION date) matched by substring most-specific first; cache write 5m/1h and read columns, Haiku 5.5 long-context tier above 100k prompt tokens, web search $10/1k, web fetch free; config `usage.pricing` overrides by substring. The `claude-api` skill's cached table is stale on Sonnet 5.5 cache reads ($0.10 is correct).
- Aggregates (`aggregate.ts`, `blocks.ts`, `savings.ts`): daily/weekly/monthly keys are LOCAL calendar days; 5-hour billing blocks are UTC floor-to-hour (ccusage semantics); burn rate only projects with ≥ 2 calls over ≥ 5 minutes; savings price eminiar's seen-vs-returned stats as direct (cache-write) plus compounding (cache-read × later calls in the session, half the session's calls when timing is unknown).
- `insights.ts` detectors with documented thresholds (cache-thrash, cache-cold, context-bloat > 8k est tokens, compaction-churn, opus-for-trivial, fast-mode-share, thinking-share, subagent-cost, expensive-turn with per-driver advice, error-loop, budget, unpriced-model, context-near-limit) and four 0..100 scores that always list reasons.
- Surfaces: em_usage tool (views summary/daily/weekly/monthly/models/sessions/blocks/turns/tools/insights/savings; text under 1 KB for summary), `/api/usage` + `/api/usage/session` (validated scope/session/since/limit, `calls` only with ?calls=1), dashboard Usage tab (per-model-id palette from `usage-helpers.ts`), CLI `eminiar usage`, statusline segments `$cost · ctx % · 5h %` with snapshots recorded only when figures change, session-start brief line, soft budget warnings once per session/day. Storage: migration v5 tables api_calls, tool_uses, context_events, transcript_files, statusline_snapshots; purge scope "usage".
Known limits: no per-request latency or HTTP status (needs OTEL or a proxy); rows ingested by pre-release builds keep old is_error flags (purge usage to rebuild); statusline_snapshots and tool_uses hold sizes and ids only, never prompt or result text.
