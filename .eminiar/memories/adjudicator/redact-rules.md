UPDATE 2026-11-10 (swarm run 20261109-82e284, PRs #54/#55): the "quoted values capped at 512" detail below is superseded. Rules are now linear-time on stored output (exec/batch/url/stderr, up to 2-5 MB): no overlapping optional-whitespace runs; the normalize trailing-space rule and maskYamlBlocks are linear; classify.ts masks BEFORE clipping to 160 chars. Hook-path cost rules (a hook is one cold process): the IGNORABLE regex is built lazily on first clean(); a cheap SECRET_HINT test precedes isSecretName; the ASSIGN_NAME name is atomic; rules needing a literal (://, login/mongo/redis-cli/ldap/zip/mosquitto_, password, pass|secret|token|api|access) are skipped when it is absent. Output must stay byte-identical: tests/unit/redact-perf.test.ts diffs against tests/fixtures/redact-before-cost-fixes.ts. Masking 780 KB once costs about 8.6 ms (execLarge400k about +8 ms vs main); redact.ts is still imported eagerly by the hook chunk via classify.ts and indexer.ts. Bash hook must stay within 1 ms over main (npm run bench: hooks --base --assert, run alone).

Adjudicator redact() design (branch feature/adjudicator, swarm run 20261104-483f39, task #34, 2026-11-04). src/adjudicator/redact.ts must stay linear on 100 KB inputs (tests/unit/adjudicator-redact.test.ts enforces < 20 ms realistic, < 100 ms per pathological input). Rules: (1) Secret `name = value` is two-step: ASSIGN_NAME (/g) finds `name<sep>` at identifier boundaries only; isSecretName() decides in code (split on _ . - and camelCase; the last word must be a secret word such as key/token/secret/pass/password/passphrase/pwd/credentials/auth/pat, or end in password/token/apikey…, optionally followed only by qualifiers like base/hash/v2), so keyEnv, apiKeyName, token_count, max_tokens, pass_through stay; only then the sticky ASSIGN_VALUE reads the value (quoted values with spaces capped at 512, bare values stop at whitespace/quote or a &;, that starts the next name=). Do not put the secret-word alternation back inside one regex with lazy/greedy identifier runs: it is quadratic. Values like ${X}, process.env.X, <placeholder>, true/false, short numbers are kept. (2) YAML block scalars under a secret key are masked line-based by maskYamlBlocks, which head()/forRemote() run BEFORE normalize() because normalize collapses indentation. (3) Every rule starting with \b and an unbounded class must start at the start of its run (lookbehind), e.g. the email rule, or `--a-a-a…` goes quadratic. (4) Rules are idempotent (lookaheads skip `***`). (5) Tasks #58/#64: clean() strips every /\p{Default_Ignorable_Code_Point}/gu char (zero-width, CGJ, variation selectors, tag chars, Hangul fillers, ALM, bidi, BOM, soft hyphen), applies NFKC, then strips again (NFKC maps U+3164/U+FFA0 to ignorable U+1160). redact() starts with clean(), and head()/forRemote() call clean() BEFORE their first maskYamlBlocks pass, so a nested block whose key hides a ZWSP or fullwidth colon is found while its indentation is intact (normalize() later collapses it). normalize()/inputHash() are unchanged (cache keys stay stable). The pathological-input timing test bounds each input by max(100 ms, 25 × a linear 100 KB baseline measured in the same test) and re-times before failing, so parallel load does not flake it while a quadratic rule (seconds at 100 KB) still fails. Homoglyphs such as Cyrillic letters are NOT folded, because that needs a confusables table and a position-preserving match. CLI password flags are tied to their tool, with the context bounded at 300 chars and stopping at ; & | (docker/podman/nerdctl/buildah/skopeo/oras/finch/helm registry/crane auth `login -p`, mongo* -p, redis-cli -a, ldap* -w, zip/unzip -P, mosquitto_* -P, 7z -pX, sshpass -p where only sshpass's own options -f/-d/-P take args, htpasswd -b/-nb, echo|printf … | … --password-stdin, --password-stdin <<<, openssl pass:, keytool -*pass, -U user%pass). There is no generic `-p` rule, so mkdir/cp/ssh/psql/docker run -p survive. psql -p is the port. .netrc is `machine H [login|account X]{0,2} password V` across whitespace/newlines, plus `default …` and line-start `login X\npassword V`. Cookie/Set-Cookie headers and curl -b/--cookie mask every value and keep cookie names and Set-Cookie attributes. Prose also covers `secret|token|api key|access key is/was <word with digit/symbol>`. Accepted as inherent: secrets split across lines; prose only masked for "password is/was <word with a digit or symbol>".
